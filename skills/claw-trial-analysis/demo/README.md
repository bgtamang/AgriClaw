# Demo data

All files are synthetic, generated by `make_demo.R` (seed 2026).

- `trial_clean.csv`: one trial (`DEMO-AI`) in the column layout that `claw-fieldbook` writes to `clean_data.csv`. It has 100 entries (98 lines and 2 checks) in 2 replicates, side by side in a 10-row x 20-column field, with incomplete blocks of 10 plots (one field row within a replicate) and `design = alpha`. Traits: `yield_kg_ha` and `plant_height_cm`.
- `true_genetic_values.csv`: the simulated genetic effect of every entry, for checking the BLUEs.

Simulation for yield: 4000 + genetic effect (SD 400) + smooth trend 500 sin(row/3) + 300 cos(col/4) + residual (SD 300). The true entry-mean heritability with 2 replicates is 400^2 / (400^2 + 300^2/2) = 0.78. Plot 57 has +1800 kg/ha added (a planted outlier), and plot 133 is missing.

The statgenSTA example data (`dropsRaw`) are used in the tests, loaded from the installed package.
