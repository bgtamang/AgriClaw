# Demo data

`stomatal_demo.csv` is synthetic, generated by `make_demo.R` (seed 20261015) in
the tidy layout written by `claw-licor-6800`. Regenerate with
`Rscript demo/make_demo.R`.

Four leaves (genotype x plot), each a 7-step light series (2000 to 200 umol
m-2 s-1) at leaf temperature 27 C, chamber CO2 400 umol/mol, chamber humidity
about 60%, gbw 2.9 mol m-2 s-1 and pressure 99.6 kPa. A follows a saturating
light response. At each point gsw is solved by fixed-point iteration so that
the **Medlyn model** holds at the leaf surface, where hs, Cs and D are computed
exactly as `PhotoGEA::calculate_gas_properties` computes them back from the
logged E, gbw, H2O_s, Ca, leaf temperature and pressure (LI-6800 manual
Appendix C). Gaussian scatter (sd 0.01 mol m-2 s-1) is added to gsw.
`vpd_leaf_kpa` mimics the LI-6800 VPDleaf (leaf to chamber air).

| genotype | plot | g0 (mol m-2 s-1) | Medlyn g1 (kPa^0.5) |
|---|---|---|---|
| G1 | 101 | 0.02 | 3.5 |
| G1 | 102 | 0.02 | 3.5 |
| G2 | 201 | 0.02 | 4.5 |
| G2 | 202 | 0.02 | 4.5 |

The Ball-Berry fit of the same data has no generating value; it shows both
models side by side.
