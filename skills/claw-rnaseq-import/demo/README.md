# Demo data

All files here are synthetic, generated by `make_demo.R` (fixed seed 20261015). Re-create them with:

```
Rscript demo/make_demo.R
```

- `annotation.gff3`: 200 invented genes (`Demo.01G000100` style, including 3 lncRNA genes) with 1-3 isoforms each, written in the Phytozome style: the `ID` attribute carries an annotation-version suffix (`Demo.01G000100.1.Dm1.v1`) while `Name` holds the plain ID used in the transcript FASTA.
- `quant/S1`..`quant/S6/quant.sf`: Salmon-format quantifications for 307 transcripts (the 305 annotated ones plus two chloroplast transcripts, `ChrC_psbA` and `ChrC_rbcL`, that are absent from the nuclear GFF3, as happens when organelle sequences are added to an index). Counts are negative binomial with dispersion 0.04; 40 genes respond to drought and 6 genes switch isoforms.
- `quant/S*/aux_info/meta_info.json`: Salmon-style mapping statistics. Sample **S6 has a planted mapping rate of 32.5%** (the others 87-90%), so it is flagged by the QC.
- `samples.csv`: sample sheet with `sample`, `path`, `condition` (control/drought) and `replicate`.

These files are not output of the real Salmon program and contain no real soybean or other crop data.
