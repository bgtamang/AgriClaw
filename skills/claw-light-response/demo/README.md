# Demo data

`light_demo.csv` is synthetic, generated by `make_demo.R` (seed 20261015) in
the tidy layout written by `claw-licor-6800`. Regenerate with
`Rscript demo/make_demo.R`.

Each curve steps PPFD down from 2000 to 0 umol m-2 s-1 (15 steps) and follows
the non-rectangular hyperbola with the parameters below, plus Gaussian noise
(A sd 0.25 umol m-2 s-1, PPFD sd 0.5).
