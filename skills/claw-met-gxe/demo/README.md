# Demo data

All files are synthetic, generated by `make_demo.R` (seed 2026).

- `met_input.csv`: per-trial genotype BLUEs in the layout that `claw-trial-analysis` writes (`trial, genotype, yield_kg_ha, se_yield_kg_ha, wt_yield_kg_ha`), plus `location` and `year`. There are 40 soybean genotypes in 8 trials (4 locations x 2 years). Three genotype x trial cells are missing (SB07 in LEWIS-2025, SB19 in AMES-2026, SB33 in NASHUA-2025), so the missing-cell handling shows in the report.
- `met_truth.csv`: the simulated genotype effects `g_kg_ha`, Finlay-Wilkinson sensitivities `sensitivity_b` and crossover scores `crossover_u`.

Simulation model: yield = 3800 + e_j x b_i + g_i + u_i x v_j + ge_ij + stage-1 error. Here e_j is the environment effect, b_i ~ N(1, 0.25^2), g_i ~ N(0, 300^2), u_i ~ N(0, 180^2), and v_j = +1 for AMES and NASHUA, -1 for LEWIS and CRAWFORDSVILLE. Also ge_ij ~ N(0, 120^2), and the stage-1 error has the trial's SE (160-380 kg/ha), which is also written as `se_yield_kg_ha`.

The test suite also runs a smoke test on `dropsPheno`, the maize multi-environment BLUEs that ship with statgenGxE (Millet et al. 2019, doi:10.15454/IASSTN), loaded with `data("dropsPheno", package = "statgenGxE")`.
