# Demo data

All values are synthetic, generated by `make_demo.R` (base R, seed 20251015). Regenerate them with `Rscript demo/make_demo.R` from the skill folder.

## `rs_yield.csv`

60 soybean-like genotypes in 4 environments (IL/IA x 2024/2025), one row per genotype x environment: 240 rows.

**Yield.** `yield_kg_ha` is built from five parts:
- the environment mean;
- maturity and early vigour of the genotype, which the sensors can see;
- other genotype yield potential, which the sensors cannot see;
- G x E;
- plot error.

**Features.** All are computed from the same latent traits plus noise:
- `greenup_dap`, `senescence_dap`, `season_length_days`;
- `ndvi_at_dap50`, `ndvi_at_dap60`, `ndvi_peak`, `auc_vi_days`;
- `precip_season_mm` and `gdd_season_c`, which are constant within each environment.

**Built-in leakage.** Each environment has a sensor calibration offset on every NDVI value, and season weather totals that are unrelated to its mean yield.
- These identify an environment without telling a model anything that transfers to a new one.
- Random k-fold therefore looks good, while leave-environment-out exposes the problem.
- Within-environment ranking of genotypes still works.

## `feature_time.csv`

The day after planting from which each feature is known: `feature, available_t`.
- Green-up and the DAP-50/60 NDVI values are treated as coming from flights up to DAP 60.
- Season-long metrics and weather totals are known only at season end.
- Use it with `--feature-time` and `--cutoff`.
