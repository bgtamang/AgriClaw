# Demo data

All values are synthetic, generated by `make_demo.R` (base R, seed 20251015). Regenerate them with `Rscript demo/make_demo.R` from the skill folder.

- `vi_long.csv`: NDVI for 24 soybean-like plots: 12 genotypes x 2 environments.
  - E1 was planted 2025-05-08 and E2 on 2025-05-29, with 15-16 flights at irregular intervals.
  - Curves follow the Beck double logistic with genotype-specific green-up and maturity, plus Gaussian noise (SD 0.015).
  - Two shadow-like drops were added: plot E1-03 at DAP 52 (-0.25) and plot E2-07 at DAP 71 (-0.18).
  - Plot E2-12 keeps only 5 flights, so it is too sparse for a curve.
  - Columns: `plot_id, env, genotype, planting_date, date, ndvi`.
- `gdd_daily.csv`: daily growing degree days (base 10 C, ceiling 30 C, deg C days) for each environment.
  - They come from a sinusoidal seasonal temperature curve with noise; E2 runs 1 C warmer.
  - Columns: `env, date, gdd_c`, the daily column name used by `claw-gdd`.
