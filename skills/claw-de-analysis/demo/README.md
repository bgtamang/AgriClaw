# Demo data

All files are synthetic, generated by `make_demo.R` (fixed seed 42). Re-create them with:

```
Rscript demo/make_demo.R
```

- `counts.csv`: raw negative-binomial counts for 1200 invented genes (`Demo.01G000100` style) in 8 samples: 4 control and 4 drought plants, 2 of each in sequencing batches `b1` and `b2`. Gene means are log-normal, dispersion follows 0.05 + 1/mean with log-normal scatter, size factors vary from 0.7 to 1.4, and batch `b2` shifts every gene by a random log2 amount (SD 0.3).
- `samples.csv`: `sample`, `condition` (control/drought), `batch` (b1/b2).
- `truth.csv`: the planted truth per gene: `true_log2fc` (drought vs control; 120 genes with |log2FC| between 0.8 and 2.5), `is_de`, `base_mean`, `dispersion`. The tests compare the demo results with this file.

The demo runs `--design "~ batch + condition" --reference condition=control`.
