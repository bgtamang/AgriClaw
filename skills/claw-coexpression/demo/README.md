# Demo data

Synthetic files generated by `make_demo.R` (fixed seed 7) with `WGCNA::simulateDatExpr`. Re-create them with:

```
Rscript demo/make_demo.R
```

- `expr_vst.csv`: 600 invented genes (`Demo.01G000100` style) × 24 samples on a VST-like log2 scale (gene means 6-12, SDs 0.3-1.2). Four modules are planted from four seed eigengenes (108, 84, 66 and 48 genes, gene-eigengene correlations 0.4-0.95); the other 294 genes are unrelated (unassigned).
- `traits.csv`: `treatment` (12 control, 12 drought; module 1's eigengene is shifted in drought plants), `stomatal_conductance_mol_m2_s` (driven negatively by module 1), `leaf_n_mg_g` (driven by module 3) and `plant_height_cm` (unrelated: a null trait).
- `true_modules.csv`: the planted module of each gene (0 = unrelated), used by the tests.
