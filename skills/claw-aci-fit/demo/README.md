# Demo data

Both files are synthetic, generated by `make_demo.R` (seed 20261015) with
PhotoGEA's own model functions, in the tidy layout written by
`claw-licor-6800`. Regenerate with `Rscript demo/make_demo.R`.

Each curve follows the LI-6800 setpoint sequence 400, 300, 200, 150, 100, 75,
50, 20, 400, 400, 600, 800, 1000, 1200, 1500, 1800 umol/mol. At every point Ci
is solved so that A = gsw / 1.6 x (Ca - Ci), with gsw rising at low CO2 and
falling at high CO2, and Ca = setpoint - 1.2 x A. Noise: A sd 0.3 umol m-2 s-1,
Ci sd 1.5 umol/mol, leaf temperature sd 0.15 C.

## aci_demo_c3.csv (C3, `calculate_c3_assimilation`, Bernacchi temperature responses, Cc = Ci)

|---|---|---|---|---|---|---|---|
| G1 | 101 | 95 | 175 | 11.5 | 1.4 | 28 | |
| G1 | 102 | 105 | 185 | 12.5 | 1.6 | 28.5 | |
| G2 | 201 | 75 | 150 | 13 | 1.2 | 28 | TPU never limits |
| G2 | 202 | 80 | 155 | 13 | 1.3 | 28.5 | Vcmax and J x 0.78 after the low-CO2 steps (loss of activation) |

Curve G2 - 202 is built to trip the induction check: A at the return to
400 umol/mol is about 20% below its starting value, and the fitted J is biased
low, which could be mistaken for down-regulation.

Mesophyll conductance 1 mol m-2 s-1 bar-1 at 25 C, bundle-sheath conductance
0.003, Rm_frac 0.5, J and Vpr 1000 (PhotoGEA's `fit_c4_aci` defaults). With
