# Demo data

Both files are synthetic, generated by `make_demo.R` (base R, seed 21):

```
Rscript demo/make_demo.R
```

- `demo_annotation.gff3`: a GFF3 annotation for an invented genome, `AgriClaw-demo-1.0`. It has three chromosomes (`Chr01` to `Chr03`; 10, 8 and 12 Mb) and 40 genes per chromosome, each with a gene, an mRNA and an exon feature. The header has `#!genome-build AgriClaw-demo-1.0` and `##sequence-region` lines, and the `Note` attributes are URL-encoded (`%2C`, `%3B`).
- `demo_qtl_regions.csv`: three QTL regions in the format written by `claw-gwas-crop` (`trait, region_id, chr, start_bp, end_bp, lead_snp, lead_pos_bp, ...`). Chromosomes are named `1` to `3`, so the demo also exercises chromosome-name matching.

Gene IDs (`AcDemo01g000100`), positions and descriptions are invented and do not describe any real genome. The live Ensembl mode is exercised in `tests/` with saved responses (see `tests/fixtures/README.md`).
