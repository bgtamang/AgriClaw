# Demo data

All files are synthetic.

- `design_field_book.csv`: the field book written by `claw-trial-design --demo` (30 entries, alpha design, 3 replicates, 90 plots, seed 2026).
- `fieldbook_database_export.csv`: simulated observations for those plots in the Field Book app "database" export layout (`plot_id, trait, value, timestamp, person, location, number`), for `yield_kg_ha`, `plant_height_cm` and `flowering_date`. Generated by `make_demo.R` (seed 2026).
- `limits.csv`: plausible ranges for the two numeric traits.

Deliberate errors in the export, all of which the QC must report:

| Plot | Error |
|---|---|
| DEMO-17, DEMO-58 | never observed |
| DEMO-5 | yield recorded as NA |
| DEMO-12 | yield digit typo (3xxx -> 6xxx): robust outlier |
| DEMO-48 | yield 35000: outside the limits |
| DEMO-33 | height -8.5: outside the limits |
| DEMO-40 | height "35,5": decimal comma |
| DEMO-61 | flowering date before planting |
| DEMO-70 | yield timestamp in 2099 |
| DEMO-22 | two conflicting yield records |
| DEMO-23 | two identical height records |
| DEMO-999 | plot ID not in the design |

The demo run uses planting date 2026-05-15 and season window 2026-05-01 to 2026-11-30.
