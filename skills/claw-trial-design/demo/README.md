# Demo data

`entries.csv` is an invented entry list: 30 soybean entries for a preliminary yield trial, of which two (`CHECK-A`, `CHECK-B`) are flagged as checks in the `is_check` column. The `pedigree` column is made up and is only there to show that extra columns are carried into the field book.

The demo (`--demo`) lays these 30 entries out as an alpha design with 3 replicates and incomplete blocks of 5 plots, seed 2026.
