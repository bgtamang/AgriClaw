# Demo data

All files are synthetic, generated by `make_demo.R` (base R, seed 42):

```
Rscript demo/make_demo.R
```

- `demo_panel.vcf.gz`: 120 inbred lines (two subpopulations) × 600 biallelic SNPs on 3 chromosomes, with 2% random missing calls and 0.3% genotyping errors. Planted problems:
  - 20 markers with 40% missing calls;
  - 10 monomorphic markers;
  - 10 rare markers (3 carriers, MAF 0.025);
  - 4 samples with 50% missing calls;
  - 3 contaminated samples (a mixture of two lines, heterozygous where they differ);
  - 3 duplicate pairs (copies with 0.5% discordant calls).
- `demo_truth.csv`: every planted problem (`problem`, `id`). The tests check that the skill reports exactly these and nothing else.

Marker names are `S<chr>_<position>`; positions and alleles are random and do not correspond to any real genome.
