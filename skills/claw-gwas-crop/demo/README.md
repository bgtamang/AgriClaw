# Demo data

All files are synthetic, generated by `make_demo.R` (base R, seeds 2 and 3):

```
Rscript demo/make_demo.R
```

- `demo_geno_012.csv.gz`: 250 inbred lines from three subpopulations (Balding-Nichols Fst 0.15), 1,347 SNPs on 5 chromosomes of 50 Mb, coded 0/2, with 1% missing calls. Each line is a mosaic of 12 founder haplotypes of its subpopulation, which gives LD that decays over a few Mb. The layout is the AgriClaw marker table (`marker, chr, pos, ref, alt`, then one column per line).
- `demo_pheno_blues.csv`: one row per line with two traits:
  - `height_cm`: 3 QTNs (about 10% of variance each), a polygenic background of 200 small-effect markers (20%), a subpopulation effect (15%) and noise;
  - `protein_pct`: no marker effects at all, only a subpopulation effect (30%) and noise. Any hit for it is a false positive.
- `demo_truth.csv`: the three QTNs for `height_cm` (marker, chromosome, position).

Marker names are `S<chr>_<position>`; positions, alleles and trait values do not correspond to any real genome or crop.
